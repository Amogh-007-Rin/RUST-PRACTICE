# Module 100: Final Capstone Support

**Block:** J — Interview Prep, DSA & Career Readiness

Module 100 is a capstone module: it has no exercise crate of its own. The
final project is **Capstone 10 — Full-Stack Rust Job-Ready Project**, which
lands at this point in the curriculum and integrates at least two
specialization blocks.

Go to [Capstone 10 — Full-Stack Rust Job-Ready Project](../../capstones/capstone-10-full-stack-job-ready-project/README.md)
and build your portfolio piece. Before you start, make sure you've completed
the career-readiness modules in this block (089, 096, 097, 098) — they tell
you how to present the finished project.
